# Fantasy Map Generator — десктопная сборка для Windows

Эта папка — автосборщик десктопной (Electron) версии под Windows.
Дважды кликните по батнику — всё остальное он сделает сам.

## Быстрый старт

| Файл | Что делает |
|---|---|
| `BUILD-INSTALL-RUN.bat` | **Всё в один клик:** проверка Node.js → установка зависимостей → сборка → EXE-установщик → запуск установщика |
| `FMG-Desktop.bat` | То же самое, но через **меню**: можно собрать без установщика, запустить dev-режим, проверить окружение, очистить сборку |
| `..\Setup-FMG.bat` | Ярлык в корне репозитория — просто открывает меню `FMG-Desktop.bat` |

## Требования

- **Windows 10/11 x64**
- **Node.js 24+** (LTS): https://nodejs.org — батник сам проверит наличие и версию
- ~2 ГБ свободного места (зависимости + сборка)
- Интернет для первой установки зависимостей

Права администратора **не нужны**: установщик ставится в профиль пользователя.

## Что получится

- Установщик: `release\fmg-<версия>-win-x64.exe` — ставит программу, ярлыки и ассоциацию `.map` файлов
- Portable-версия: `release\win-unpacked\Fantasy Map Generator.exe` — работает без установки, можно носить на флешке
- Двойной клик по `.map` файлу открывает карту в программе
- Обновления: программа сама проверяет GitHub-релизы + пункт меню «Справка → Проверить обновления»

## Возможности десктопной версии

- **Меню:** Файл (открыть `.map`, папка данных) → Правка → Вид (перезагрузка с подтверждением, масштаб, полноэкранный) → Производительность (переключатель GPU-ускорения, советы) → Окно → Справка (вики, Discord, баг-репорт, обновления)
- **Оптимизации без потери функций:** GPU-растеризация SVG-карты, отключение троттлинга фона (генерация не встаёт при сворачивании), `backgroundThrottling: false`, кеширование бандла, быстрый старт (`compression: store`), десктопный таргет сборки
- **Надёжность:** диалог при зависании/падении рендера с кнопкой перезагрузки, подтверждение выхода, восстановление окна на видимом мониторе

## Частые вопросы

**SmartScreen ругается «Windows protected your PC».**
Установщик без платной цифровой подписи — это нормально для open-source.
Нажмите «Подробнее» → «Выполнить в любом случае».

**Антивирус удалил файл.**
Эвристика иногда реагирует на NSIS-установщики. Добавьте папку `release` в исключения и соберите заново.

**`npm ci` упал с ошибкой сети.**
Проверьте интернет/прокси/VPN и запустите снова. Как запасной вариант батник сам пробует `npm install`.

**«Требуется Node.js 24+».**
Установите свежий LTS с https://nodejs.org и перезапустите батник. Старый Node можно удалить через «Установку и удаление программ».

**Хочу начисто пересобрать.**
Пункт меню `7` (очистка) → затем `1` (полный цикл).

**Карта тормозит на слабом ПК.**
В программе: «Вид → Производительность» — попробуйте выключить аппаратное ускорение (помогает со старыми драйверами) и почитайте «Советы по производительности». Также помогает пресет «Скорость» в настройках приложения (шестерёнка → Performance).

## Своя иконка установщика
